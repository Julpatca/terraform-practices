# Terraform Cloud Infrastructure Practices

## Overview

This repository contains hands-on Terraform exercises developed while learning Infrastructure as Code (IaC) and cloud infrastructure automation.

The exercises cover Terraform fundamentals and AWS infrastructure provisioning, progressing from basic resources to more reusable configurations.

## Topics Covered

- **Terraform Fundamentals:** Providers, version constraints, and resource definitions.
- **Amazon S3:** Bucket creation and resource configuration.
- **Amazon VPC:** Network provisioning, including multi-region concepts.
- **Terraform Variables and Outputs:** Parameterized configurations and resource information.
- **Amazon EC2:** Instance configuration and initialization scripts.
- **Dynamic Configurations:** `count`, `for_each`, `locals`, and dynamic blocks.
- **Terraform Modules:** Exploring modular infrastructure configurations.
- **Local Resources:** File creation and random value generation.

## Repository Structure

Each directory contains an individual exercise or a related set of Terraform configuration files.

## Tools and Technologies

- Terraform
- Amazon Web Services (AWS)
- AWS Provider for Terraform
- Linux / Ubuntu on WSL

## Learning Goals

- Practice Infrastructure as Code principles.
- Build and configure cloud resources using Terraform.
- Improve configuration reusability through variables and modules.
- Explore resource iteration and dynamic configuration patterns.

## Disclaimer

These projects are for learning and laboratory purposes. Review configurations, authentication settings, and potential costs before deploying resources in any AWS account.
